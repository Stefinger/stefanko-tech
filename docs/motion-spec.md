# Stefanko.tech — Motion Specification

## Principle

Motion must explain how an unclear idea becomes a real product.

Do not animate elements only for decoration.

## Motion hierarchy

1. Signature Blob S
2. Scroll-driven section transitions
3. Headline entrances
4. Question blobs
5. Decision timeline
6. Product assembly layers
7. Product proof reveals

## Navbar

- Fixed at the top
- No separator line
- Multi-wave organic bottom
- At the top it visually merges with the hero
- Over cream sections the wave becomes visible
- Mobile hamburger uses an organic blob border

## Desktop

- Richer scroll choreography
- Cursor interaction allowed
- Blob S may remain pinned between selected scenes
- Larger spatial movement

## Mobile

- No cursor interaction
- Shorter pinned sections
- Reduced movement distance
- Avoid overlaps
- Prefer vertical progression
- Provide static fallback for weak devices

## Accessibility

Respect prefers-reduced-motion.

Reduced motion should:

- remove pinned cinematic sequences
- remove cursor reactions
- keep content readable in normal document flow
- preserve basic opacity transitions only
